# Simple-Quiz-Game
A simple console-based quiz game built in Python using loops, if-else statements, and dictionaries to ask questions, check answers, and track score.
## Features
- Multiple questions stored as a list of dictionaries
- Loops through each question one at a time
- Checks user input against the correct answer (case-insensitive)
- Tracks and displays your final score at the end

## Concepts used
- Lists and dictionaries
- `for` loops
- `if-else` conditional statements
- String methods (`.lower()`, `.strip()`)
- User input handling.
